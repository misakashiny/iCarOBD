# 环境配置与验证

2026-10-14现行要求；历史换机说明原件在归档ZIP。版本来自Gradle配置；本机路径只是示例。

## 环境

- Windows/PowerShell；JDK21（项目Java/Kotlin字节码17），Android SDK，Node（生成/测试），Edge（浏览器套件）。Python仅用于本轮整理工具，不是App运行依赖。
- SDK平台35，build-tools按AGP解析；当前仍需要NDK29.0.14206865与CMake3.31.6，因为LVGL尚在构建。
- Gradle8.14.3由wrapper获取；AGP8.13.0、Kotlin2.2.20按锁定配置使用。本轮不升级依赖。
- local.properties是本机SDK定位，不提交；工具链下载缓存不属于源码交接包。

```powershell
# 在仓库根目录执行；先建立ASCII联接，再创建联接下的临时目录。
$projectRoot = (Get-Location).Path
if (-not (Test-Path -LiteralPath D:/icarobd)) {
    New-Item -ItemType Junction -Path D:/icarobd -Target $projectRoot | Out-Null
} elseif ((Get-Item -LiteralPath D:/icarobd).Target -ne $projectRoot) {
    throw 'D:/icarobd已存在且目标不同，请核对并使用另一ASCII联接，不要覆盖'
}
$env:JAVA_HOME = 'C:/Program Files/Eclipse Adoptium/jdk-21.0.12.101-hotspot'
$env:ANDROID_HOME = 'C:/Android/Sdk'
# 本机JDK Unix-domain临时路径故障使用ASCII临时目录。
New-Item -ItemType Directory -Path D:/icarobd/stage/jvm-tmp -Force | Out-Null
$env:JAVA_TOOL_OPTIONS = '-Djdk.net.unixdomain.tmpdir=D:/icarobd/stage/jvm-tmp'
[Environment]::SetEnvironmentVariable('ORG_GRADLE_PROJECT_kotlin.incremental','false','Process')
```

run-tests.ps1也能创建/核实ASCII联接；使用JAVA_TOOL_OPTIONS示例时应先按上方建立联接，避免临时目录提前占用联接路径。已有联接必须核对目标，不覆盖。项目含中文/空格时，通过ASCII路径执行JVM；保持--no-daemon。SDK/JDK真实安装位置可调整，不要求复制旧电脑账户路径。

## 命令与判据

```powershell
powershell -ExecutionPolicy Bypass -File tools/run-tests.ps1
# 上条成功后再构建；从ASCII联接运行。
Set-Location D:/icarobd
./gradlew.bat :app:assembleDebug --no-daemon --console=plain
node tools/icarui/tests/verify-crosslang.js
powershell -ExecutionPolicy Bypass -File tools/run-browser-tests.ps1
node tools/check-doc-links.js
powershell -ExecutionPolicy Bypass -File tools/check-build-guard.ps1 -Apk app/build/outputs/apk/debug/app-debug.apk
node tools/iteration-board/build.js
```

- 每步保存退出码，失败不要继续宣称通过。JVM失败/错误/跳过必须均0，浏览器按原断言基线检查。
- 若打包出现重复ZIP或增量产物异常，只在保存旧包并核对绝对路径后移除单个debug APK再assemble；不默认全局clean。
- 浏览器运行器会清理测试浏览器进程，必须串行；禁止同时运行多个Gradle/浏览器批次。
- ICarUI日常双击tools/icarui/start-icarui.cmd；serve.cmd只用于直开受环境影响时的兜底。PNG与内嵌数据同时存在有file直开用途。
- Git空白检查使用git -c core.whitespace=cr-at-eol diff --check；裸检查会将已有Windows行尾判作空白，须报告差异，不批量改历史行尾。

## 设备与隐私

设备验证不包含在纯构建命令中。授权后先adb devices -l核实transport，再用-s指定设备；配置/设计/素材先备份，升级用install -r且验证包哈希。不清数据、不卸载、不自动连接适配器、不发车辆请求。

签名材料、local.properties、个人AI会话和设备备份不放公共交接包。完整本地备份含私有文件，只在本机保管。交接不能依赖任何AI软件的聊天恢复能力。
