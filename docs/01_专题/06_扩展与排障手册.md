# 扩展与排障手册

现行操作摘要，2026-10-14。原1140行手册和换机文档逐字保存在整理前文档原件ZIP；这里不再保留过时“当前状态”。架构红线只在[架构](../04_架构与数据流.md)，字段只在主题/模型权威处维护。

## 新增或修改车辆数据

1. 优先在PID编辑器添加/测试/保存，检查mode、参数、header、单位、公式和量程，再绑定仪表。
2. 内置定义或公式实现变更必须经过PidRequestPolicy最终请求检查，保持轮询/测试/扫描的请求安全。
3. CAN信号必须有实测ID/位/端序/缩放依据；未确认的数据源标为待验，不能给缺失灯/挡位猜PID。
4. 模型字段变化同步JSON往返、兼容迁移、App/ICarUI解析及跨端回归；旧设计/用户配置不可静默破坏。

## 新增仪表或主题

纯绘制视图接收值，不创建传输或读取适配器。缺失/过期/非有限输入显示未知，合法0有效；旧值不能因内部缓存继续画正常皮肤。状态、阈值与颜色共用现有规则。

修改节点树、子部件、素材包时查专题12/13；icar.ui/1仍兼容，icar.ui/2是当前节点系统。icar.control/2为工具控件包装，不等同App设计包；App已有icarzip导入，但所有新库整包的实际像素未验。

## 排障顺序

| 现象 | 首查 |
|---|---|
| 蓝牙连接失败 | 权限/设备/传输，BLE GATT表与写属性；SPP有实现但需硬件验证 |
| AT/OBD超时 | ElmSession串行请求、模式门禁、协议/头与实际日志，不并发补发 |
| 数值错误 | 严格响应解析、公式、单位、范围、TTL/Source；不要把未知当0 |
| 停止后还显示旧值 | 来源是否关闭、旧回调代际、派生/视图缓存；不全局clear |
| 导入后变扁/素材缺失 | 节点坐标单位与图像比例、基目录/引用、旧格式迁移 |
| CSV/告警异常 | 原始值有效性、会话/队列/规则状态，保留日志限流与有界缓冲 |

## 保护与验证

改配置/导入/设备升级前备份；取消或失败时不能误覆盖原配置。保持日志重复抑制、文件上限、有界队列和批量通知。构建/验证命令见环境文档；车辆操作必须按专题16工单与任务授权执行。
