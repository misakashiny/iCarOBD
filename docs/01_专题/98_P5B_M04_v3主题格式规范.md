## 一、设计原则

1. **只做增量**：v3 = v2 的超集。v2 的所有字段与语义**一字不改**。
2. **不强制迁移**：v2 主题重新保存仍是 v2（除非用户主动加新节点）。
3. **不静默降级**：v3 → v2 的转换**不存在**。要降级必须显式操作且有提示。
4. **通用字段复用**：`x/y/w/h/rotation/scale/alpha/z/locked/visible/children` 全部沿用 v2 定义。
5. **不使用 `meta.requires`**（任务 §一 第 7 条）：实测旧版完全不读它，无作用。

|---|---|---|---|---|---|---|

| `prefix` | string | `""` | 任意 | 前缀 | 前缀 | 原样 |
| `suffix` | string | `""` | 任意 | 后缀 | 后缀 | 原样 |
| `valueLabels` | array | `null` | 字符串数组 | 数值→文字 | 同上 | 原样 |
| `size` | number | 28 | 1..200 | 字号（画布单位）| sp | 原样 |
| `unitSize` | number | 12 | 1..100 | 单位字号 | sp | 原样 |
| `align` | int | 1 | 0=左 1=中 2=右 | 对齐 | 对齐 | 原样 |
| `color` | string | `#FFFFFF` | `#RRGGBB` | 正常色 | 正常色 | 原样 |
| `warnColor` | string | `#FFB020` | `#RRGGBB` | 警告色 | 警告色 | 原样 |
| `criticalColor` | string | `#FF4D4F` | `#RRGGBB` | 危险色 | 危险色 | 原样 |

### 3.2 `shape`（基础图形）

| 字段 | 类型 | 默认值 | 有效范围 | Win | Android | 导出 |
|---|---|---|---|---|---|---|
| `kind` | string | `"rect"` | `rect`/`roundRect`/`circle`/`ring`/`line`/`polyline` | 分派 | 分派 | 原样 |
| `fill` | string | `#3DD6FF` | `#RRGGBB` 或 `"none"` | 填充 | 填充 | 原样 |
| `stroke` | string | `"none"` | `#RRGGBB` 或 `"none"` | 描边 | 描边 | 原样 |
| `strokeWidth` | number | 0 | 0..100 | 线宽 | 线宽 | 原样 |
| `cornerRadius` | number | 12 | 0..(min(w,h)/2) | 圆角 | 圆角（夹取）| 原样 |
| `innerRatio` | number | 0.6 | 0.05..0.95 | ring 内径比 | 同 | 原样 |
| `points` | array | `[]` | `[{x,y}]`，归一化 0..1 | polyline | 同 | 原样 |

### 3.3 `segmentedArc`（分段圆环）

| 字段 | 类型 | 默认值 | 有效范围 | Win | Android | 导出 |
|---|---|---|---|---|---|---|
| `pid` | string | `""` | PID | 取模拟值 | `VehicleBus` | 原样 |
| `minVal` / `maxVal` | number | 0 / 100 | `maxVal > minVal` | 量程 | 量程 | 原样 |
| `startAngle` | number | 150 | 任意（度，0=3点钟）| 起始角 | 同 | 原样 |
| `sweepAngle` | number | 240 | −360..360（负=逆时针）| 扫角 | 同 | 原样 |
| `segmentCount` | int | 24 | 1..360 | 分段数 | 同 | 原样 |
| `gapAngle` | number | 2 | 0..90 | 段间空隙（度）| 同 | 原样 |
| `thickness` | number | 12 | 0.5..(min(w,h)/2) | 线宽 | 同 | 原样 |
| `activeColor` | string | `#FF3D7F` | `#RRGGBB` | 点亮色 | 同 | 原样 |
| `inactiveColor` | string | `#4A5058` | `#RRGGBB` | 未点亮色 | 同 | 原样 |
| `zoneColors` | array | `[]` | `[{at,color}]` | 分区色 | 同 | 原样 |
| `noDataColor` | string | `#FF4D4F` | `#RRGGBB` | 无数据色 | 同 | 原样 |
| `radiusRatio` | number | 0.42 | 0.05..0.5 | 半径占比 | 同 | 原样 |

**进度语义**：`progress = (value - minVal) / (maxVal - minVal)`，夹到 [0,1]，**按段四舍五入点亮**。

**无数据**：不点亮任何段，整圈用 `noDataColor` 压暗。

### 3.4 `pathProgress`（曲线进度）

| 字段 | 类型 | 默认值 | 有效范围 | Win | Android | 导出 |
|---|---|---|---|---|---|---|
| `pid` | string | `""` | PID | 取模拟值 | `VehicleBus` | 原样 |
| `minVal` / `maxVal` | number | 0 / 100 | `maxVal > minVal` | 量程 | 量程 | 原样 |
| `points` | array | `[]` | `[{x,y}]` **归一化 0..1**，最多 **64** 点 | Catmull-Rom 200 段 | PathMeasure | 原样 |
| `curve` | int | 0 | 0=平滑 1=折线 | 平滑/折线 | 同 | 原样 |
| `thickness` | number | 6 | 0.5..100 | 线宽 | 线宽 | 原样 |
| `activeColor` | string | `#3DD6FF` | `#RRGGBB` | 已完成色 | 同 | 原样 |
| `inactiveColor` | string | `#2A3038` | `#RRGGBB` | 未完成色 | 同 | 原样 |
| `gradientTo` | string | `"none"` | `#RRGGBB` 或 `none` | 渐变终点 | 同 | 原样 |
| `fill` | bool | false | — | 面积填充 | 同 | 原样 |
| `fillColor` | string | `#3300C8FF` | `#AARRGGBB` | 填充色 | 同 | 原样 |

**无效控制点保护**：NaN/Infinity 被滤掉，越界坐标夹到 0..1。

## 四、版本判定规则（B2）

### 4.1 新版（Android + 编辑器）

```
schema == "icar.ui/1"  → v1 路径（gauges 数组）
schema == "icar.ui/2"  → v2 路径（pages/nodes）
schema == "icar.ui/3"  → v3 路径（pages/nodes + 四种新 type）
其他                    → 明确拒绝
```

### 4.2 保存行为

| 当前主题 | 用户操作 | 结果 |
|---|---|---|
| v2，未加新节点 | 保存 | **仍是 v2**（不强制升级）|
| v2，加了任一 v3 节点 | 保存 | **升级为 v3** |
| v3，未改动 | 保存 | 仍是 v3 |
| v3，删掉所有 v3 节点 | 保存 | **仍是 v3**（不自动降级）|

### 4.3 不静默降级（硬规则）

**不存在** v3 → v2 的自动转换路径。若要导出 v2，必须：
- 显式选择"导出为 v2（会丢弃 N 个新控件）"
- 且显示会丢弃哪些节点

### 4.4 未知关键节点

v3 主题里若有**不认识的 type**：
- **必须产生明确错误或不可忽略的警告**（不允许静默跳过）
- 不允许"静默输出缺少重要动态仪表的主题"

## 五、错误与警告分级

| 情况 | 级别 | 行为 |
|---|---|---|
| schema 不认识 | **error** | 拒绝加载 |
| v3 里的未知 type | **error** | 列出所有未知节点，拒绝加载 |
| `pathProgress.points` > 64 | **error** | 拒绝该节点并说明上限 |
| `maxVal <= minVal` | **error** | 拒绝该节点 |
| `cornerRadius` 超限 | warning | 夹取 |
| `segmentedArc.gapAngle` ≥ 每段角 | warning | 夹到最小正角 |
| PID 不在库中 | warning | 允许（用户可能后导入）|
| 未知 kind（shape）| warning | 回落 rect |
