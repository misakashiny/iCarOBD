# 截图索引

实机截图（小米平板 5 / Android 13 / 1600×2560 @360dpi）。
**用途**：接手时快速建立界面印象；改 UI 后对照检查是否走样。

> ⚠️ 排查像素级问题时：预览工具会把截图**缩放显示**，
> 估算点击坐标要按比例换算回物理像素 ——
> 横屏（2560×1600）用 **2.370**，竖屏（1600×2560）用 **2.374**。
> 拿不准就先 `adb exec-out screencap -p` 看一眼当前方向。
