## 阶段 B：正式实现 v3

### Android 侧

新增文件：
- `PrimitiveFields.kt` —— 四基元共用字段容器
- `PrimitiveParser.kt` —— 四个 `parseXxx()` 纯函数

`DesignFile.kt`：加 `SCHEMA_V3`、`isTree`、`parseNodeArray(allowV3)`。
`DesignNode.kt`：加 `TYPE_VALUE_TEXT/SHAPE/SEGMENTED_ARC/PATH_PROGRESS`、
`TYPES_V2`/`TYPES_V3_ONLY`、`parse(allowV3)`、`prim` 字段。

### 编辑器侧

新增 `js/registry/controls/primitive-family.js`（4 条控件定义）。
`schema.js`：`SCHEMA_V3`、`V3_NODE_TYPES`、`schemaForDesign()`。
`model.js`：`createNode` 通用 pid 分支、`nodeToJson` 四基元字段、`toV2Json` 自动选 schema。
`validate.js`：认 v3、`_allowV3` 传播、四基元字段解析、`parsePointsSoft`。
`canvas.js`：`drawPrimitiveNode` + 未知节点占位。

**v3 → v2 的自动降级路径不存在**（任务 §四 B2 硬规则）。
