## 三、最小验收流程（约 12 分钟）

```bash
# 1. 装包（ARM64 设备；x86 模拟器装不上，见报告未完成事项）
adb install -r app/build/outputs/apk/debug/app-debug.apk

# 2. 导入两个测试包（设置页 → 导入画布 → 选文件）
#    docs/02_验证记录/android-theme/state-lamps/state-lamps.icarzip
#    docs/02_验证记录/android-theme/parts-gauge/parts-gauge.icarzip

# 3. 状态灯三态（对应 ①②）
adb shell am broadcast -a com.icar.obd.SIM --es scenario normal
adb shell am broadcast -a com.icar.obd.SIM --es scenario alarm
adb shell am broadcast -a com.icar.obd.SIM --es scenario critical

# 4. 子部件（对应 ③④⑤）
adb shell am broadcast -a com.icar.obd.SIM --es scenario accel --ei step 40
adb shell am broadcast -a com.icar.obd.SIM --es scenario disconnect
adb shell am broadcast -a com.icar.obd.SIM --es scenario recover --ei step 10

# 5. 宽屏观感（对应 ⑦）
adb shell wm size 1280x600
adb shell wm density 160
#   …看完恢复：
adb shell wm size reset
adb shell wm density reset
```

## 四、已知限制（不是 bug，不用报）

| # | 现象 | 说明 |
|---|---|---|
| 1 | 平板/宽屏上元素被拉伸 | `SCALE_STRETCH` 是 v1 契约（每轴独立缩放）。FIT 可解决但会留白 |
| 2 | 低电压时不报警 | 状态灯**只支持高值阈值**，已登记缺口 |
| 3 | 用 parts 拼表时指针不动 | 若指针没显式绑 PID，量程取**节点 min/max（默认 0..100）**。请在节点上写 `min`/`max`（见报告建议）|
| 4 | 模拟器帧率偏低 | 软件渲染（swiftshader），真机会好得多 |
| 5 | 旋转屏幕时模拟器崩 | 该 AVD 的 swiftshader 限制，非应用问题 |
| 6 | x86 模拟器装不上 APK | 只打了 `arm64-v8a`（为省 LVGL 编译时间）|
