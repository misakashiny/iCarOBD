### 两个 M03 遗留问题的判定

| 问题 | 判定 |

| Ctrl+Y 重做未验证 | ✅ **已解决**（非缺陷）—— M03 当时撤销本身没生效，重做无法独立判定 |

### 修复方式

用「**每轮重新定位 + 谓词等待**」代替固定延迟 → 连续 3 轮真实输入 **3/3 通过**。

### 🔴 新发现并修复的真实产品缺陷

**属性面板输入后「点画布空白处」丢失撤销记录**

| 项 | 内容 |
|---|---|
| 复现 | 选中控件 → 属性面板改数值 → **点画布空白处**失焦 → Ctrl+Z 无效 |
| 根因 | 点空白清空 `CanvasState.selection` → `change` 处理器 `selectedNode()` 返回 null → 提前 return → **`endLive()` 永不执行** |
| 影响 | 用户最常见的「改完点旁边确认」会导致修改**无法撤销** |
| 修复 | ① `PropertyUpdate` 暴露 `currentNodeId()`/`currentPath()`<br>② `change`/`blur` 在选中丢失时用 live 事务的 nodeId 兜底 |
| 回归 | E1-3b（Ctrl+Z 250→180）、E1-5（Ctrl+Y 180→250）|
