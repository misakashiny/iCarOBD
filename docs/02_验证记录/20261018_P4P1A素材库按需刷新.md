# 20261018 P4P-1A 素材库按需刷新

详见专题：[48_ICarUI_P4P1A素材库按需刷新](../01_专题/48_ICarUI_P4P1A素材库按需刷新.md)
历史问题：[37_LegacyBehaviorDebt](../01_专题/37_LegacyBehaviorDebt.md)（新增 D-14）

## 一、性能证据复核

P4P-0 推算 renderAssets 25.7ms → **本阶段直接测量 24.7ms**，吻合，方案无需调整。

内部拆解：
  HTML 字符串       242,611 字符
  innerHTML 写入+解析   5.4 ms
  JS 字符串拼接（推算） 约 19.3 ms

规模：416 内置素材 + 215 内置控件 + 12 分类 —— 与画布内容无关。

## 二、依赖清单（11 项）

design.assets（逐字段）/ BUILTIN_ASSETS / BUILTIN_CONTROLS /
design.controls / assetKindList / assetQuery / collapsed /
panelCollapsed / havePath（已用角标）/ data（缩略图）/ matchPinyin（静态）

其中 assetQuery、collapsed、panelCollapsed 是**闭包变量**（D-14）。

## 三、机制

内容签名 + 显式强制：
  force=true → 重建（5 个闭包状态操作入口）
  签名不同  → 重建
  签名相同  → **直接 return，不碰 DOM**
  计算异常  → 重建（保守兜底）

不用引用/长度比较的原因：实测「删+加（长度不变）」必须被识别到。

## 四、12 类素材变化全部覆盖

新增/删除/改名/改分类/改路径/改 data/导入设计/切换设计/
撤销/重做/搜索/内置列表变化 —— **12/12 全部触发重建，零漏刷**。

## 五、普通编辑 0 次重建

8 种属性编辑 + 轨道 fill + 容器 w/h：**rebuilt=0, skipped≥8**

DOM 保留实测：
  同一缩略图 DOM 元素 ✅
  同一搜索框 DOM 元素 ✅
  滚动位置 120→120 ✅
  折叠状态不变 ✅
  拖拽/点击属性保留 ✅

## 六、前后性能（50 样本，同环境）

| 场景 | P4P-0 基线 | P4P-1A | 改善 |
| --- | --- | --- | --- |
| 空设计 | 21.80 | **0.2** | 99.1% |
| 20 控件 | 28.80 | **12.5** | 56.6% |
| **60 控件** | **43.7** | **17.8** | **59.3%** |

refreshAll 从 ~30ms 降到 ~2ms（改善 94%）。
素材 DOM 重建次数：**0/100**（五个场景全部）。

素材真变时 renderAssets(true) 仍需 22.1ms —— 正确性代价，一分不少。

## 七、剩余 17.8ms 的构成

**saveUndoStack 同步写 localStorage 约 18.3ms** ← 本阶段禁止修改
其余（draw/syncJson/renderTree）< 2ms

## 八、优化过程中打坏的 3 个既有套件（已修）

verify-assets(1) / verify-fix(3) / verify-feat2(1)
根因：折叠态是闭包变量，签名读不到 → 5 个入口改强制刷新。
修复后全部恢复，无断言被删除或放宽。

## 九、测试

51 套 / 5826 断言 / FAIL=0；JVM 1365 项 0/0/0。
功能套件只测「重建次数」这个确定性指标，**不测绝对耗时**，
避免机器负载造成 CI 不稳定失败。
