## 风险

| ID | 描述 | 优先级 |
|---|---|---|
| **R1** | **Schema 直写 `pid` 破坏双字段**：实测写入 `obd.rpm` 后 `pid=obd.rpm`（别名进通道位）、`rawPid=obd.speed`（未更新）| **P0** |
| R2 | `normalizeStateLampBinding` 无法解析时静默跳过（实测 resolvePid 永不返回空，故无"残留旧通道"，但无效别名会进 statePid）| P1 |
| R3 | `label`/`unit`/`font.size`/`font.color` 在 schema 但**不序列化**（改后保存不住）| P1 |
| R4 | UNKNOWN 状态无配置字段（要做得改数据契约）| P2 |
| R5 | `P4D-GUI-001` 卡片缺失 | P2 |

### R1 证据

```
改前: pid=std_0D  rawPid=obd.speed
写 'obd.rpm' 后: pid=obd.rpm, rawPid=obd.speed, 序列化=obd.rpm
重载后: pid=obd.rpm, rawPid=obd.rpm  ← 双字段同时错
```

对比：旧面板 `assignControlBinding()`（data-bindings.js:36）**正确**设置两字段。
结论：缺陷在 Schema 路径，不在旧面板。

### R3 证据

6 个仪表 schema 均声明 12 字段，但序列化只有 15–17 个键，
`label`/`unit`/`font.size`/`font.color` **始终缺席**。
