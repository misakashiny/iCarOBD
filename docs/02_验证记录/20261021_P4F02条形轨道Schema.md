## 阶段一：7 个字段审计

| 字段 | 类型 | 默认 | 范围 | 特殊控件 |
|---|---|---|---|---|
| trackStyle.radius | number | short/2 | 0..64 | 否 |
| trackStyle.inset | boolean | false | true/false | 否 |
| trackStyle.gradient | **string 枚举** | null | null/fade/gloss | 否 |
| trackStyle.ticks | number | 0 | 0..64 | 否 |
| trackStyle.band | boolean | false | true/false | 否 |
| w | number | 240 | ≥1 | 否 |
| h | number | 16 | ≥1 | 否 |

**关键结论 1**：任务要求「不能假设 gradient/ticks/band 是简单类型」——
实测源码确认三者分别是 **string / number / boolean**，
**均非对象或数组**，无需复合编辑控件。

**关键结论 2**：track 控件**默认就带完整 trackStyle 对象**
（不同于 gauge 的 `card` 默认 null），
所以 `PropertyAccessor.set` 可直接写子路径，**无需 normalizeCardPath 那类逻辑**。

## 阶段二：实现

`normalizeTrackStyle`、`MAX_TRACK_TICKS`、`TRACK_GRADIENTS` 逐条对齐。
