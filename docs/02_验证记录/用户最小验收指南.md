# 用户最小验收指南

**日期**：2026-10-21｜**任务**：`T-UI-REFACTOR-P4F-M03`

## 为什么需要你做

自动化已经覆盖了 **35 项**（共 62 项 GUI 验收条目），但有些事情**只有你能判断**：

- 画面看起来对不对（AI 模型不支持读图，只能生成截图不能判读）
- 真实设备的触屏手感
- 真实车载平板上的实际效果

**你只需要做完下面 2 个场景，约 25 分钟**，就能覆盖全部 27 项需人工确认的内容。

## 场景 1：Windows 编辑器（约 15 分钟）

> 打开 `tools/icarui/index.html`

### ① 仪表：色带与子部件（覆盖 P4E-GUI-001 ①②③、P4F-GUI-004 ①②③④⑤⑥⑦⑧）

1. 拖一个**仪表**到画布，点它
2. **看右侧属性面板**：应该有 23 行，往下能看到「多段色带」「子部件」
3. 点「＋加一段」两次 → 出现两行色带
4. 把第一行颜色改成绿色 → **画布上应该立刻出现绿色色块**
5. 点第一行的「✕」删掉 → 色块消失
6. 点「按阈值生成」→ 自动生成红区色带
7. 点「＋加部件」→ 出现一行部件
8. 再点一次 → 两个部件
9. 点第二个的「↑」→ **看画布上图层顺序是否变化**（谁压谁）
10. 连续按 Ctrl+Z 三次 → 逐步回退
11. 连续按 Ctrl+Y 三次 → 逐步恢复

### ② 图片：清晰度与切换（覆盖 P4R-GUI-001 ①②③⑥、P4F-GUI-002 ①②③④）

1. 从素材库导入一张**手机拍的照片**（不是小图标）
2. 拖到画布上
3. **看图片是否清晰**（不应该糊成马赛克）
4. 在属性面板把「素材」下拉换成另一张 → **画布应立即换图，且依然清晰**
5. 改「宽度」「高度」→ 边框应跟着变

### ③ 轨道：10 种样式（覆盖 P4F-GUI-001 ④–⑨）

1. 拖几个**条形轨道**到画布
2. 分别试：调圆角、开渐变、开发光、加刻度、加分段、开色带
3. **对照** `docs/02_验证记录/screenshots/` 下的 `track-01-plain.png` … `track-10-glow.png`
4. 看效果是否符合预期

### ④ 文字与容器（覆盖 P4F-GUI-003 ①②③④）

1. 拖一个**文字** → 改内容、改宽度、改高度
2. 拖一个**容器**，里面放 2 个控件
3. 改容器的「缩放」为 1.5 → **子控件应跟着放大，但相对位置不变**
4. 改回 1 → 应完全复原

### ⑤ 保存与恢复（覆盖 P4F-GUI-004 ⑧、P4R-GUI-001 ④）

1. 前面的改动做完后，**刷新浏览器**
2. 应弹出「恢复草稿」提示 → 点恢复
3. **检查色带、部件、图片是否都还在**

## 场景 2：Android 平板（约 10 分钟）

> **这是最关键的一步** —— 轨道样式能不能在平板上看到，就看这里

### ① 制作并导出测试设计（在 Windows 上）

1. 做一个设计，包含：
   - 一张**普通图片**（照片）
   - 一个**状态灯**
   - 3~5 个**条形轨道**，分别设：圆角大/小、开渐变、开刻度、开色带
2. 导出设计文件

### ② 导入平板（覆盖 P4F-GUI-004 ⑨⑩）

1. 把设计文件传到平板
2. App 里：横滑到最后一页（设置页）→ 点「导入画布」→ 选文件 → 点「导入」
3. 如果有「这份设计还需要素材」提示，选「选择素材文件夹」把图片一起导入
4. **看画布上的条形轨道**：
   - ✅ 应该能看到**代码绘制的轨道**（圆角、渐变、刻度、色带）
   - ❌ 如果只看到一张底图或空白 → **这就是问题，请记录**

### ③ 两端对比（覆盖 P4F-GUI-004 ⑩）

1. 平板和电脑**并排放着**
2. 对比同一个轨道的：颜色、圆角、渐变方向、刻度数量、色带位置
3. **记下明显不一样的地方**

### ④ 状态灯（覆盖 P4D-GUI-001 ①–⑦）

1. 连上车（或开模拟数据）
2. 看状态灯是否按真实数据切换亮/灭
3. 看仪表数值是否正常跳动
