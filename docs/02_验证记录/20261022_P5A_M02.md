## 阶段 A：基线核查 + 两处历史描述更正

### 更正 1：`openSource` → `put(v)` 的**实际代价**（M01 只记了"改了什么"）

写编译探针确认 `internal` 在 `app/src/debug/` 里确实不可见（与 M01 观察一致）。
但 M01 没写清代价，本轮用 `VehicleBusSourceSemanticsTest`（13 项）钉住：

- `put(source,v)` → `closeSource`：值 `ok=false`、`error="采集来源已停止"` ✅
- `put(v)` → `closeSource`：值**仍 `ok=true`** ❌（因为 `put(v)` 内部 `currentOwners.remove(pidId)`）
- 附带：该 PID 脱离 epoch 保护；归属在真实/模拟间来回漂

### 更正 2：「`app/src/main` 未变更」是**错的**

`git show --stat 379826f` 实测：4 个文件 **+109 −2** 行
（`TrackView.kt` +66−1、`NodeTreeRenderer.kt` +30、`DashRenderer.kt` +6、`DesignNode.kt` +9−1）。
准确表述应为：**`app/src/main` 只做了轨道接数据这一处缺陷修复**。

### 其他审计要点

- `ObdController.startPolling/stopPolling` + `engine.running` 是唯一开关
- `DashRenderer.pushValues()` 5Hz 分四路：gauges / trackViews / partsViews / stateCells
- **状态灯只判高值**（`value >= warnAt`），无 warnLow
- `GaugePart.pid` **只在 needle/value 上生效**
- APK 只打 `arm64-v8a` → `qz33`（Android 13，仅 x86_64）**装不上**

## 阶段 B：数据源隔离（**最高优先级**）

**方案**：复用 `SignalSimulator`（`openSource` + `put(source,v)`，v1.5.0 既有）
+ 严格互斥 + 默认关闭 + 看门狗。**生产代码 0 改动**。

```
开：engine.stop()（互斥）→ 场景写通道 → SignalSimulator.start()
关：SignalSimulator.stop() → closeSource → 全部 ok=false
看门狗：每 2s 检查，真实轮询起来 → 模拟自动退让
```

- 场景 11 档：normal/accel/decel/warmup/**alarm(warn档)**/**critical**/disconnect/recover/
  nullpid/missing/multi
- `alarm` 与 `critical` 的取值**来自 `NodeStateResolver` 实际算法**：
  车速 warn120→critical190、转速 6500→7250、水温 105→160
- ADB：`am broadcast -a com.icar.obd.SIM --es scenario critical --ei step 5`；`--es dump 1` 打总线值

**隔离实测**（dex 字节搜索）：

| 变体 | dex | 含 `com/icar/obd/sim` | manifest 含 SimInitProvider |
|---|---|---|---|
| DEBUG | 10 | 1 | 是 |
| RELEASE | 2 | **0** | 否 |

⚠️ Release **仍含** `SignalSimulator`/`SimulatorActivity`（既有产品功能）—— 表述必须说准。

**总线实测**：`disconnect` 后 `BUSD` 全部 `ok=0 err=采集来源已停止`
（M01 版这里是 `ok=1`，是错的）。

### 🔴 修复缺陷：`GaugePartsView` 只用单一缩放比例

- 现象：`gB` 有指针，`gA`/`gC` 没有；嵌套件全缺
- 根因：`GaugePartsView` 只收一个 `pxPerUnit`，X/Y 同比例；而 `Viewport` 是 **pxX/pxY 分别算**
  （手机竖屏 pxX=3、pxY=6.31）→ 部件横向放大 2.1 倍溢出被裁，pivot 落到 View 外，
  且 `drawPart` 提前 return 导致 children 一起不画
- 修复：构造改 `pxX, pxY`（保留单比例次级构造，pxX==pxY 时逐像素一致）
- 影响面：**所有用 parts 拼表 + 非正方形视口**的主题

### 另一处"不是缺陷"的坑（登记建议）

指针未显式绑 pid 时，量程回落**节点 `min`/`max`（默认 0..100）**。
主 PID 量程不是 0..100 时指针会**钉在端点**。第一版测试主题漏写量程就踩了。
建议工具侧创建 parts 表时自动写入 PID 量程（登记 `P5A-M02-PARTS-RANGE`）。
