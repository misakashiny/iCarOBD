## 一、背景

P4F-03 为普通图片新增了 **`image` 族**，接管原旧面板 `imageFields()` 的功能：

| 字段 | 说明 |
|---|---|
| `assetId` | 素材选择（下拉，非文本框）|
| `w` / `h` | 宽高 |
| `rotation` | 旋转 |
| `scale` | 缩放 |
| `alpha` | 透明度 |

同时修正了 `isPlainImage()` 把状态灯误判为普通图片的缺陷。

**P4R-FIX-01（高清图片草稿恢复）是本轮最高优先级防回归项。**
