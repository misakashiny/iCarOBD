## 阶段一：三字段审计

| 字段 | 默认 | 范围 | schema | 持久化 | Android |
|---|---|---|---|---|---|
| text `w` | 120 | ≥1 | 已声明 min:1 | ✅ | 既有字段 |
| text `h` | 20 | ≥1 | 已声明 min:1 | ✅ | 既有字段 |
| container `scale` | 1 | ≥0.05 | 已声明（本任务 0.01→0.05）| ✅ | 既有字段 |

### 关键审计结论

1. **无文字自动测量** —— `measureText`/`autoSizeText`/`fitText`/`textMetrics` 全部 undefined
   → 改 w/h **不会破坏任何自动布局**（本项目本就没有该能力）
2. **容器 scale 语义** —— `model.js:12`「scale 是 w/h 之上的额外倍率」；
   `localMatrix` 是唯一矩阵源，**未重构**
3. **子节点绝对坐标** —— 实测容器 `scale=2` 后子节点仍为 `(10,10)`，坐标未被改动
4. **Undo/Redo 无冲突** —— 三者均走 `commit()`，与通用变换共用撤销栈

### 唯一调整

`container-family.js` 的 `scale` schema 是 `min:0.01`，旧面板 `setNodeNum` 用 `Math.max(0.05, …)`。
**schema 比旧面板宽松** → 对齐为 `min:0.05`。
