## 一、背景

P4F-M01 做了三件事：

1. **多段色带**接入 Schema 面板（行编辑器）
2. **子部件**接入 Schema 面板（行编辑器）
3. **Android 轨道绘制**（消除 `TRACK-APP-001` 技术债）

前两项有自动化覆盖（51 断言），第三项**只有编译与算法对齐**，视觉效果必须人工确认。
