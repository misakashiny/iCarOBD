## 三、最小验收流程

如果只有 15 分钟，请按这个顺序做 **①②⑤⑥⑦**：

```bash
# 1. 装 Debug APK（模拟数据源只在 Debug 里有）
adb install -r app/build/outputs/apk/debug/app-debug.apk

# 2. 导入测试主题
#    App → 设置页 → 导入画布 → 选 designdata-bind.json

# 3. 打开模拟数据
adb shell am broadcast -a com.icar.obd.SIM --es scenario normal --ei step 20

# 4. 看仪表（对应 ①②）→ 切场景看变化（③④）
adb shell am broadcast -a com.icar.obd.SIM --es scenario accel --ei step 40

# 5. 看断开（⑤）与恢复（⑥）
adb shell am broadcast -a com.icar.obd.SIM --es scenario disconnect
adb shell am broadcast -a com.icar.obd.SIM --es scenario recover --ei step 10

# 6. 重点核对轨道（⑦）—— 这是本轮修的缺陷
adb shell am broadcast -a com.icar.obd.SIM --es scenario alarm --ei step 10
```

## 四、已知限制（不是 bug，不用报）

| # | 现象 | 说明 |
|---|---|---|
| 1 | 平板/宽屏上元素被拉伸 | `SCALE_STRETCH` 每轴独立缩放，是 v1 契约。设计文件可写 `scaleMode:1` 换等比 |
| 2 | 状态灯看不到三态 | 测试主题没带素材，需自备 |
| 3 | 模拟器帧率偏低 | 软件渲染（swiftshader），真机会好得多 |
| 4 | 旋转屏幕时模拟器崩溃 | 该 AVD 的 swiftshader 限制，非应用问题 |
