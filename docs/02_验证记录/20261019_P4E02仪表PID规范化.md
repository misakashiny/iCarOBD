## 批次 A：PID 双字段规范化

**根因**：`nodeToJson` 写 `ALIAS_OF[n.pid] || n.pid`；若只写 `node.pid='obd.rpm'`（别名），
则别名进通道位、`rawPid` 不动，重载后**两个字段同时错**。
旧面板 `assignControlBinding()` 写法正确 → 缺陷在 Schema 路径。

**修复**：新增 `normalizeGaugePidBinding()`，在 `PropertyAccessor.set` 入口拦截。

| 输入 | pid | rawPid | 序列化 |
|---|---|---|---|
| `obd.rpm` | `std_0C` | `obd.rpm` | `obd.rpm` |
| `std_0C` | `std_0C` | `std_0C` | `obd.rpm` |
| `''` | `''` | `''` | — |
| `tpl_oilPressure` | `tpl_oilPressure` | `tpl_oilPressure` | `tpl_oilPressure` |
| `xx.unknown` | `xx.unknown` | `xx.unknown` | `xx.unknown` |

**导出 JSON 中 pid 始终为别名 → `icar.ui/2` 契约未变。**
