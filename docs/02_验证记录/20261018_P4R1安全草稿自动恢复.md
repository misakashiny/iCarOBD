## ⚠️ 零、纠正 P4R-0 的「剥离 data」建议（D-17）

P4R-0 曾建议草稿只存 path 不存 data。P4R-1 实测证明这会导致用户图片永久丢失。

决定性证据：
  当前会话：  fetch(blobUrl) → OK status=200  url=blob:null/d3feef6d-...
  刷新之后：  fetch(同一 blobUrl) → **FAIL: Failed to fetch**

blob:null/xxx 只活在创建它的文档里，刷新即失效。

→ 本阶段实施方案 A：**完整保存设计快照，含 asset.data**。

## 一、七类素材来源审计

| 来源 | 字段 | 刷新后 |
| --- | --- | --- |
| 内置图片（416 条）| path + data（双份）| ✅ |
| assets/ 相对路径 | path | ✅ |
| **用户拖入** | data（dataURL）| ✅ |
| Base64 内嵌 | data | ✅ |
| **Blob URL** | 运行时 | ❌ **失效** |
| 自定义控件图片 | 复制进 data | ✅ |
| 图片丢失 | 紫框大 X | — |

实测 416 条内置素材**全部同时有 path 和 data**（allHaveBoth: true）。

## 二、⚠️ file:// 下 IndexedDB 可用性（任务明确要求验证）

实测（项目真实运行环境 file://）：
  origin: file://
  typeof indexedDB: object
  open: **OK**
  事务提交: **COMMITTED**
  读回: {"k":"a","v":"hello"}
  配额: **10,737,419,880 字节（10.7 GB）**

**IndexedDB 在 file:// 下完全可用**（Chromium/Edge）。

## 三、数据结构与事务

数据库 icar-studio-drafts（v1），store "drafts" keyPath draftId：
  draftId / designId / designName / savedAt / schemaVersion /
  designJson（含 assets.data）/ selection / nodeCount / assetCount /
  byteSize / checksum / manualSavedAt / **complete**

三层原子性保证：
  1 单事务原子提交（put 要么整条写入要么完全没写）
  2 **complete 完成标记**（false 判为"未完成写入"）
  3 **FNV-1a 校验和**（检测截断/篡改）

8 种场景实测（空/60控件/5图/20图/100图/嵌套/next_*/混合）：
  **8/8 写入成功、读回 problem: null**

## 四、设计身份

designId **不进 design 对象、不进 toV2Json 输出**，只存在 DraftManager 模块状态 + IndexedDB。

实测：
  designId 出现在导出 JSON 里 → **不出现**
  设计文件有 _id 字段 → **没有**
  同名设计存 2 份 → count: 2, distinctIds: 2 ✅

## 五、自动保存触发与防抖

设计变更入口审计：所有数据变更走 commit()/replaceDesign()；
选择节点/面板折叠/鼠标移动**不触发**。

防抖 1200ms，依据：序列化 0.2ms + 写入 1.0ms + 打字间隔 200~400ms。

**30 次连续 commit（5 秒）→ 实际保存 1 次** ✅

必须记录的四件事：
  · 编辑后立即标 dirty，**延迟 1200ms** 才真正写
  · 保存完成 = 防抖到期 + IndexedDB oncomplete（约 1ms）
  · 连续编辑产生 **1 次**写入
  · 异常退出最坏损失 **约 1200ms + IndexedDB 落盘时间**的编辑

**不承诺零数据丢失。**

## 六、完整恢复实测

刷新后画布 5 个预设控件（**未被自动覆盖**）
提示条显示：「图片恢复测试 · 刚刚 · 10 个控件 · 1 张素材 · 3 KB」

## 七、八条安全约束

✅ 1 启动绝不自动覆盖
✅ 2 恢复前校验
✅ 3 有未保存改动需确认
✅ 4 删除需二次确认
✅ 5 稍后再说绝不删数据
✅ 6 新建不覆盖旧草稿
✅ 7 恢复失败不清除副本
⚠️ 8 不兼容草稿的**"导出原始数据"救援按钮未实现**（只显示损坏原因）
