### 缺陷与修复

**旧代码**：撤销蓝牙权限后 `startForegroundCount = 0`（带类型与无类型**都没成功**）。
根因：Manifest 声明 `foregroundServiceType="connectedDevice"` 后，Android 14 对
**无类型调用也按 Manifest 校验** → 降级走不通。后果：不崩了但 Service 非前台。

**修复**：权限前置检查 + 场景化类型：
- 有权限 → `CONNECTED_DEVICE`（正常路径完全不变）
- 无权限 → `DATA_SYNC`（不需蓝牙权限，仍给 FGS 保护）
- Manifest 加 `connectedDevice|dataSync` + `FOREGROUND_SERVICE_DATA_SYNC`

**实测**：`startForegroundCount` **0 → 1**。
