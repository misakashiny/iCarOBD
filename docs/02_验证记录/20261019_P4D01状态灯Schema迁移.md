## 审计发现

| 项 | 结论 |
|---|---|
| Registry 状态灯 | 19 条，`render.mode = "state"`，schema 11 字段且 19 个完全一致 |
| SchemaResolver 原状 | 只分发 container / text / track，**无状态灯分支** |
| `__controlKey` | **不进序列化**，重载后必然丢失 → 必须靠持久化特征识别 |
| 数据契约 | `rawStatePid`=别名、`statePid`=通道 id、序列化 `statePid`=别名 |

## 实现（4 处最小改动，均在 schema-props.js）

1. `EDITABLE.imageState` —— 11 个开放字段
2. `isStateLamp()` —— 靠 `type==="image"` + `states` 对象 + 无 `trackStyle` 识别
3. `stateLampSchemaFor()` —— 从 Registry 取代表定义，不复制 schema
4. `normalizeStateLampBinding()` —— `statePid` 双字段同步，在 `PropertyAccessor.set` 入口拦截
