### 发现并修复的阻断性缺口

**复现**：传入 stack:'NOT-AN-ARRAY' 时 saveDraft 仍 ok:true 并写入无效历史。
**修复**：写入前最低锚点校验（designId/draftRevision/stack/index/historyAvailable），
不合法则降级为仅草稿可用并 delete 旧历史。

## 历史格式一致性

- 正式字段唯一规范：historyFormatVersion=2
- 正式记录不含原型旧字段 schema
- 原型旧字段 schema=2 仍被兼容接受
- 未知格式（99）拒绝 schema-mismatch
- 部分记录损坏 → 整包 fail-closed
- redoPersisted 如实为 false
