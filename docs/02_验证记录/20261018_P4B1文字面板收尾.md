## 一、Schema 统一（任务第二部分）

审计认定 `t_label` 的 `font.size.max=200` 是 **P1A 试点遗留**：

  来源：git log -S 'max: 200' → 提交 4346908（P0.5+P1A 试点）
  当时注释：「属性 Schema —— P1A 只登记、不驱动 UI」
  旧面板 panels.js:980 输入框只有 min="1"、**无 max**
  normalizeFont 也只判 size > 0

所以 200 与 400 都是人为值，200 更是占位。统一为 **400**。

实测：`distinctSignatures: 1`、`counts: [12]`、`maxVals: {"400": 12}`

六项约束全部满足：key 不变、默认字号/颜色/字重不变、存量设计不变、
保存前后规则一致、normalizeFont 未改（schema.js 零改动）。
未新增任何持久化字段。

## 二、保存前后校验规则一致

同一 t_label 保存前/重载后：max 都是 400，600 都拒绝、300/400 都接受。
P4B 遗留的「重载后 200→400 不一致」已消失。
