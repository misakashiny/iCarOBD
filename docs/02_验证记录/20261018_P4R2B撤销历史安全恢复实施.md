## 关卡 A：同库同事务

- DB 升级到 v3，新增 `undoHistory` store（keyPath=designId）
- 单事务：查 tombstone → CAS → 写草稿 → 写/删历史
- 历史记录含 designId/draftRevision/historyFormatVersion/stack/index/currentDesignDigest/historyAvailable/unavailableReason/savedAt

## 本阶段修复的两个真实缺陷

1. **历史版本字段不一致**：原型校验读 `schema`，正式记录写 `historyFormatVersion`
   → 所有历史永远 schema-mismatch，无法恢复（实测）
2. **删除草稿未删历史**：writeOk=false 但 getHistory 仍可取到
   → 改为同事务一并 delete
