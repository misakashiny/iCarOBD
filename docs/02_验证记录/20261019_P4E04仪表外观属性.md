## 专项：extraPids = [] 行为

| 检查 | 实测 |
|---|---|
| 空数组在 JSON 中 | **省略该键**（model.js:830 的 `if (n.extraPids.length)`）|

已修正为：**空数组时省略该键，重载由 `|| []` 兜底**。
