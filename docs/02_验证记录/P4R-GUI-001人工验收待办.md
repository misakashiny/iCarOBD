## 五、恢复验收时的建议步骤

```
③ Undo/Redo：
   恢复草稿 → 按 Ctrl+Z 三次 → 记录画布与"可撤销 N 步"计数
   → 按 Ctrl+Y 两次 → 确认回到第二步的状态

④ 历史降级：
   用 DevTools 把 IndexedDB 里 undoHistory 的 stack[0].state 改坏
   → 刷新 → 恢复草稿 → 应提示"历史不可恢复"但设计完整

⑤ 双标签页：
   同一草稿在两个标签页分别恢复 → 两边各改不同属性 → 都保存
   → 第二个保存的应看到冲突提示，且本地改动仍在

⑥ 损坏草稿导出：
   把某草稿的 checksum 改坏 → 刷新 → 提示条应显示"损坏"
   → 点"导出原始数据" → 确认下载到 JSON 且草稿仍在

⑦ 中文输入法：
   真实 Windows 微软拼音 → 在文字控件里打"你好世界"
   → 组合过程中按 Ctrl+Z → 确认不会误撤销设计
   → 候选词选择、回车提交 → 确认草稿正常保存
```
