## 项目与技术栈

iCarOBD2包含Android车辆仪表App和ICarUI浏览器主题工具。App通过ELM327兼容适配器采集数据，提供PID管理/探测、CAN探测/监听、多画布仪表、规则告警、日志与CSV；目标是“添加PID→验证→保存→绑定仪表”。

App使用Kotlin、Android View/Canvas、协程、ViewBinding；AGP8.13.0/Kotlin2.2.20/Gradle8.14.3。minSdk24、compileSdk35、targetSdk34，仅arm64；本机JDK21，字节码目标17。当前版本1.20.22/code91。

ICarUI位于tools/icarui，原生HTML/CSS/JavaScript，直接打开index.html即可用；Node负责生成/验证。最近正式工具日志版本v2.91.0，此后存在未发布修复。不要按旧日志推定工作树已发布。

## 核心链路

BLE/SPP传输→ElmSession串行请求→ObdEngine/PidScanner/CanSniffer/FrameMonitor→VehicleBus→仪表/规则/记录。模拟与G力也是数据来源。

UI车辆操作由ObdController协调；纯绘制视图接收值。配置由Store/设计包管理，主题格式与App/工具必须保持跨语言一致。详细约束见[架构](04_架构与数据流.md)；期望边界不等于所有旧代码已符合。

## 环境与常用命令

先按[环境](02_环境配置与验证.md)配置JDK/SDK与ASCII联接D:/icarobd。本机问题的JAVA_TOOL_OPTIONS与增量编译设置也在那里，不照搬旧电脑路径。

```powershell
powershell -ExecutionPolicy Bypass -File tools/run-tests.ps1
Set-Location D:/icarobd
./gradlew.bat :app:assembleDebug --no-daemon --console=plain
node tools/check-doc-links.js
powershell -ExecutionPolicy Bypass -File tools/check-build-guard.ps1 -Apk app/build/outputs/apk/debug/app-debug.apk
node tools/icarui/tests/verify-crosslang.js
powershell -ExecutionPolicy Bypass -File tools/run-browser-tests.ps1
node tools/iteration-board/build.js
```

App与浏览器验证串行。不开车、不连适配器也能跑本地回归；设备/车辆验收另行授权。不要使用旧dist包冒充新构建。
