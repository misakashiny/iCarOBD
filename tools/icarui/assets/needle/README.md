# 指针

指针图形（会被旋转，注意**枢轴点**放在图片中心）

## 用法

1. 把图片放进这个目录
2. 在工具里打开设计文件 → 左侧「素材库」→ 点 **指针** 分类上的 ＋ 导入
   （或者直接把图片**拖到素材库/画布**上）
3. 工具会把它登记成 `assets/<分类>/<文件名>`，并写进设计文件

## ⚠️ 路径规则

设计文件里存的是**相对路径**（`assets/needle/xxx.png`）。
所以整个 `assets/` 目录要和 `design.json` **一起**拷贝到设备上，
并且保持同样的相对位置。

App 侧读的就是这个相对路径 —— 换台设备、换台机器都靠它。
